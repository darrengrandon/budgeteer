# Budgeteer

Read SPEC.md for what this is. The work is in tasks/, in dependency order.

- Run ./check.sh before saying anything is done. It must pass.
- Never edit a test to make it pass. If a test looks wrong, stop and ask.
- Fix bugs test-first: write a failing test that reproduces it, then fix it.
- Money is integer cents everywhere. Format to dollars only for display.
- Languages: HTML, CSS and plain JavaScript (ES modules) only. No TypeScript, no frameworks, no build step, no network calls. Use JSDoc comments for types.
